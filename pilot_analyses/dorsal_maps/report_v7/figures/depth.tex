We averaged draws within session, then averaged sessions with equal weight. Purple shading shows the standard error across BWM sessions. Green lines show the mean for mesoscope decoders, fit with the same number of units and draws using all isocortex ROIs in each session as the sampling pool (149, 148, 149, and 149 sessions for panels e--h, respectively).
