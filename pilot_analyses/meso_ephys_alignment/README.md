# meso_ephys: task coding vs spontaneous dimensions (BWM vs mesoscope pilot)

Pre-registered in `HYPOTHESIS.md` (hash and time in `HYPOTHESIS.sha256`, written before any analysis).
Report: `report/main.pdf`. Verdict (2026-10-23): not supported; do not expand the cross-modal comparison.

```bash
python extract.py        # output/features/*.npz (grey-screen 1-s bins, task window means)
python analyze.py        # output/alignment.pqt, kcurves.npz  (pre-registered analysis)
python sensitivity.py    # output/sensitivity.pqt  (review round 1, post hoc)
python sensitivity.py --n-sweep   # output/n_sweep.pqt (meso N = 30..200, post hoc)
python figures.py        # report/figures/*.pdf
cd report && tectonic main.tex
```
Use the `iblenv` environment. BWM spikes come from the cached openalyx passingSpikes tables; meso data comes from `meso_loader.py` at the repo root.

`output/features/` (~220 MB, regenerated by `extract.py`) is not tracked.
